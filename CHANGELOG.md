# История изменений

Все заметные изменения проекта документируются в этом файле.

## 0.3.0 — 2026-09-02

- автономный нативный дистрибутив для Ubuntu Server 24.04 LTS и Debian 12 x86_64;
- установка одной командой без Docker и интернета на целевом сервере;
- служба `systemd` от отдельного непривилегированного пользователя;
- локальный центр сертификации и HTTPS для Planner и Portal;
- ограничение доступа по IPv4-подсетям для одной или нескольких VLAN;
- скрипты управления пользователями, подсетями, резервными копиями и удалением;
- автоматическая сборка, smoke-тест и публикация Linux-архива в GitHub Releases.

## 0.2.0 — 2026-09-02

- автономный дистрибутив для Windows Server;
- локальные раздельные базы и файловые хранилища Planner и Portal;
- HTTPS-шлюз с локальными пользователями и защитой от подмены заголовков;
- установка, автозапуск и правила брандмауэра без Docker и WSL;
- скрипты добавления пользователей, резервного копирования и удаления;
- пошаговая русская инструкция для установки в одной или нескольких VLAN.

## 0.1.0 — 2026-09-02

- первая публичная Community Edition;
- рабочий планировщик и отдельный клиентский портал;
- многопроектные публичные ссылки с PIN-кодом;
- скачивание опубликованных документов;
- согласование этапов, обратная связь и лента обновлений;
- демонстрационные данные без сведений рабочего экземпляра;
- шаблоны конфигурации, CI и проверка исходников на приватные идентификаторы.
