# Участие в разработке

Спасибо за интерес к Kontur Community Edition.

## Перед началом

1. Создайте отдельную ветку от `main`.
2. Не используйте реальные данные компаний, клиентов или сотрудников в тестах и примерах.
3. Не добавляйте токены, PIN-коды, рабочие URL и резервные копии.
4. Сохраняйте разграничение между закрытым планировщиком и публичным порталом.

## Проверка изменений

```bash
npm run setup
npm run check:public
npm test
```

Pull request должен кратко объяснять цель изменения, затронутые сценарии и способ проверки. Изменения схемы данных должны включать новую миграцию; уже опубликованные миграции не редактируются.

Для крупных изменений сначала создайте Discussion или Issue с описанием предлагаемого поведения и влияния на безопасность.
